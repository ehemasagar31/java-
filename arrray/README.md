# Array Programs

This folder contains Java programs related to array operations, algorithms, and manipulations.

## Programs Included:

### Basic Operations
- **Traversal.java** - Forward traversal through array
- **BackwardTraversal.java** - Backward traversal through array
- **forwardTraversal.java** - Forward array traversal
- **reversearr.java** - Reverse an array

### Searching & Sorting
- **Searching.java** - Search operations on arrays
- **searchofelement.java** - Search for specific element
- **Sorting.java** - Array sorting algorithms
- **SortingandReverseSorting.java** - Sort and reverse sort array

### Array Manipulations
- **Insertion.java** - Insert elements in array
- **Updation.java** - Update array elements
- **Update3rdValueinArrayList.java** - Update 3rd value in ArrayList
- **insertend.java** - Insert element at end
- **specificpositioninsert.java** - Insert at specific position
- **MoveZerostoRight.java** - Move all zeros to right

### Calculations & Analysis
- **SumOfElementsArray.java** - Sum all array elements
- **sumofelements.java** - Calculate sum of elements
- **averageelements.java** - Calculate average of elements
- **largestelement.java** - Find largest element
- **smallestnumber.java** - Find smallest number
- **CountOfUniqueElements.java** - Count unique elements
- **Countoccurrence.java** - Count occurrence of elements
- **alernate01.java** - Alternate 0 and 1 pattern

### Advanced Operations
- **UnionOf2Arrays.java** - Union of two arrays
- **HashsettoArray.java** - Convert HashSet to Array
- **FrndsArrayList.java** - ArrayList operations
- **Deletion.java** - Delete operations on linked list
- **DeleteNodeAtPosition.java** - Delete node at specific position

---
All programs are implemented in Java and demonstrate various array manipulation techniques and algorithms.
