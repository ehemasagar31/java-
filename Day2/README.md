# Day 2 - Java Beginner Programs

This folder contains fundamental Java programs demonstrating basic programming concepts.

## Programs Included

### 1. **Calculator.java**
- Performs basic arithmetic operations (+, -, *, /)
- Takes two numbers and an operator as input
- Handles division by zero

### 2. **EvenOdd.java**
- Checks whether a number is even or odd
- Uses modulo operator (`%`)

### 3. **FibonacciSeries.java**
- Generates Fibonacci sequence up to n terms
- Demonstrates loop control and variable manipulation

### 4. **Greeting.java**
- Simple program that takes user's name and displays a greeting
- Introduces Scanner for input and String concatenation

### 5. **ArmstrongRange.java**
- Finds all Armstrong numbers (narcissistic numbers) within a given range
- An Armstrong number equals the sum of its digits each raised to the power of the number of digits
- Example: 153 = 1³ + 5³ + 3³

## How to Run

For any Java file in this directory:

```bash
# Compile
javac Calculator.java

# Run
java Calculator
```

## Key Concepts Covered

- Input/Output with Scanner
- Conditional statements (if-else)
- Loops (for loop)
- Basic arithmetic operations
- String manipulation
- Mathematical functions (Math.pow)
